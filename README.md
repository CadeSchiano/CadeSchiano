## Featured Projects

### [Repolume](https://github.com/CadeSchiano/ai-resume-github-analyzer)
Evidence-based resume and GitHub profile analyzer. Upload a resume and GitHub username to receive a deterministic readiness report with practical next steps for software-engineering roles.
- **Live:** [ai-resume-github-analyzer.vercel.app](https://ai-resume-github-analyzer.vercel.app/)
- **Stack:** FastAPI • Next.js • React • TypeScript • GitHub API • pypdf
- **Key features:** Resume parsing • GitHub evidence analysis • Role-based readiness scoring • Optional AI explanations

### [Scrimnet](https://github.com/CadeSchiano/collegiate-scrims)
Practice-first platform for verified collegiate Rocket League teams to find, schedule, and coordinate scrims. Replaces fragmented Discord coordination with a structured workflow.
- **Live:** [scrimnet.vercel.app](https://scrimnet.vercel.app/)
- **Stack:** Next.js • React • Supabase • PostgreSQL • Row Level Security • Realtime
- **Key features:** Team verification • Scrim marketplace • Private match workspace • Realtime chat & check-ins • Role-based access control

### [NFL Quantitative Game Model](https://github.com/CadeSchiano/nfl-model)
Full-stack sports analytics project combining reproducible data pipelines, scikit-learn models, and interactive dashboards for NFL pregame forecasting, MLB predictions, and college-football projections.
- **Stack:** Python • FastAPI • SQLAlchemy • pandas • scikit-learn • React • Vite
- **Key features:** Chronological feature engineering • Trained model artifacts • Immutable prediction records • Market comparison • Deterministic evaluation metrics
